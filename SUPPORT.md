# Support

Tech Passport is a free, open-source community utility published by Tartanleaf.com Inc. It is not a managed service and does not include a promise of individual support, uptime, fixes, security monitoring, or continued development.

## Bugs and feature ideas

Use [GitHub Issues](https://github.com/gregweir/tech-passport/issues) for reproducible bugs and focused feature suggestions. Before opening an issue, check whether a similar one already exists. Do not include passwords, recovery codes, personal records, exported Passports, or other sensitive information.

## Security concerns

Do not open a public issue for a suspected vulnerability. Follow the private reporting instructions in [SECURITY.md](./SECURITY.md).

## Using the application

The [README](./README.md), in-app guidance, and documentation in [`docs/`](./docs/) describe the intended use and important limitations. General technology guidance and project updates are available from [Tartanleaf](https://www.tartanleaf.com/).
